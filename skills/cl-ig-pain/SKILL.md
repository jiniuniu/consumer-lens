# IG 痛点雷达

输入一个产品词，输出**这个品类在 Instagram 上被骂什么**，按语义聚成痛点簇。
结果用 `cl_save` 存到本机。

⚠️ **这不是一次搜索，是循环逼近。** 标签池是 IG 上唯一可靠的召回入口，
而一个标签准不准**只有搜过才知道**。看命中率，弃掉差的，从共现标签里长出
新的再搜 —— **跑三到五轮是正常的**。

⚠️ **这里找的是「买之前的顾虑」和「刷到时的反应」**，和 Reddit 那个模块不一样：

```
IG（本模块）      刷到爆款 → 怀疑/跟风翻车/不适合我     买前顾虑、内容选题
Reddit（cl-reddit-pain）  买回家用了两周 → 具体哪坏了     改品、详情页答疑
```

两者都叫「痛点」但人群不同：IG 上说话的大半**还没买**。
所以这份报告的用途是**详情页要先回答什么**，不是产品该改什么。

## 工具

| 工具 | 干什么 |
|---|---|
| `cl_ig_hashtag` | 一轮标签搜索（多标签 × 页） |
| `cl_ig_comments` | 拉帖子评论 |
| `cl_save` | 结果落到本机 |

⚠️ **主力信号走 caption，评论只做交叉验证。** caption 覆盖率 100%，
而评论一次只拿回 ~11 条、消耗是取帖的 8 倍。标签探测放开跑，评论要省着用。

---

## 1. 第一轮：给 2-3 个种子标签

**种子怎么挑**（这一步选得好，后面省一半调用）：

| 好的种子 | 为什么 |
|---|---|
| `<品类>review`、`<品类>reviews` | ★**首选**。测评标签里天然混着差评，实测命中率最高 |
| `<品类>fails`、`<品类>mistakes` | 品类 + 失败叙事，**只有大品类**才有这种标签 |
| `<品类>haul`、`<品类>tryon` | 开箱/试用，翻车内容藏在里面 |
| 卖家标签（`sheinnails`） | 买家会在卖家标签底下抱怨 |
| ~~`skincare`~~、~~`cutenails`~~ | 纯品类词/审美词，全是种草，命中率 4-8% |

```
cl_ig_hashtag { tags: ["pressonnailreview", "pressonnailsfail", "nailhaul"], pages: 1 }
```

⚠️ **小众品类没有「品类+失败叙事」标签。** 实测 `#pressonnailsfail` 全站只有
3 帖。这时候换**行为标签**（review / haul / tryon）或**卖家标签**。

**种子可以大胆多给几个** —— `pages: 1` 的探针一个标签只花 1 次，
猜错立刻弃掉（见下一节）。

## 2. 标签探针：第一页就决定弃不弃

**`pages: 1` 跑完，看每个标签那行的命中率。** 工具已经把建议打在行尾：

```
# ig 标签  命中78条 高信号23
#    24条(新24) 命中率 29%  #pressonnailreview
#     3条(新3)  命中率  0%  #pressonnailsfail  ← 标签太小(3条)，弃
#    30条(新28) 命中率  7%  #nailhaul          ← 几乎没痛点语言，弃
```

| 看到 | 怎么做 |
|---|---|
| 第一页 <12 条 | 标签太小，**弃**（全站就那么点帖，翻页也没有） |
| 命中率 <15% | 几乎没痛点语言，**弃**（多半是纯种草标签） |
| 命中率 >25% | 好标签，**对它单独翻 2-3 页** |

★ **探针是省钱的关键。** 小众品类会撞上大量空标签，探针让它们只花 1 次调用
就被弃掉而不是翻满 3 页。实测 press-on-nails 从 19 次降到 12 次。

**弃掉的标签不要再传回去。**

## 3. 循环：从共现标签长出下一轮

每轮输出末尾有一段共现标签 —— 那是**从高信号帖的 caption 里长出来的真实
相关标签**，免费带回来的（实测覆盖 22/24），比自己猜准得多：

```
# 共现标签（高信号帖里长出来的，下一轮的候选）  #dupealert:11 #nailsdidnotlast:7 …
```

挑 2-4 个看起来像「有人在抱怨」的传回去：

```
cl_ig_hashtag { tags: ["dupealert", "nailsdidnotlast"], pages: 1 }
```

**什么时候停**（三个信号，任一出现就收工）：

| 信号 | 含义 |
|---|---|
| 高信号帖 ≥ 25 | 够聚 4-8 个簇了 |
| 连续两轮新增高信号 < 3 | 池子挖空了 |
| 共现标签那行是「无」 | 高信号帖里没长出新词 |
| 累计调用 ≈ 20 次 | 兜底，超了先问用户 |

★ **判停用「新增高信号」，不用「重复率」。** 实测 IG 翻页 24/30/30
**零重复**，重复率永远踩不下去，拿它当停止条件等于没有刹车。
池子挖空的表现是「新捞上来的都不是信号」，不是「捞到重复的」。
这条和 Reddit 那边不一样，别照抄。

## 4. 拉评论 —— 只挑最值的 8 帖以内

```
cl_ig_comments { codes: ["CfwRnTrprxx", "..."] }
```

**挑的标准**（三条都要满足）：

1. **评论数 ≥30** —— 一条 5 评论的帖子清掉表情往往只剩 1-2 条，买不到东西
2. **痛点分高或互动量大** —— 评论消耗大，只花在最可能出证据的帖子上
3. **不是转发** —— 输出里标了 `↻转发自xxx` 的跳过，评论区和原帖重复

看到 `原始15 留下0  ← 全是刷屏` 不是抓取失败，是互赞团整屏刷同一个 🙌 ——
**别重试**，那个评论区本来就没东西。

## 5. 读数据：先认清 IG 的四个偏性

**① 86% 是 Reel，但这不代表「没文本」。**
实测 caption 覆盖率 100%，且 reel 的平均文案 **532 字**，比单图 post 的
239 字还长一倍（reel 靠 caption 堆关键词吃搜索流量）。
**不要按媒体类型过滤** —— 真按 post 筛会从 96 条掉到 4 条。

但要**标注**：`reel` 的 caption 是「为算法写的」，语气更夸张、更标题党；
`post` 更接近真人说话。这个差异就是判断「真实抱怨 vs 流量内容」的依据。

**② 区分创作者内容和真实抱怨。**
IG 上大量「Top 5 FAILS 😱」是为流量做的选题，不是这个人真的受了苦。
看 `💰投放` 标记、是不是品牌号、文案是不是格式化列表 —— 是的话在
`description` 里说明，别当成用户自述。

**③ 样本有偏，不能做定量陈述。**
标签池 + 平台热度排序，不是随机样本。结论里不能写「用户普遍认为 X」，
只能写「热帖里有一簇在说 X，占抓到的 N 条的约 M%」。

**④ 多语种是常态。** 实测混了西语、葡语、德语、印地语。
**不要按语种过滤** —— 拉美和南亚的 IG 电商很活跃，那些信号有价值。
非英文的照样读，痛点不分语言，但 `zh` 里要给中文意思。

⚠️ **痛点分（`痛N`）只是排序信号，不是判定。** 那是正则命中数，用来让你先读
最可能有料的。**0 分完全可能是真痛点**（用户用了正则没覆盖的说法），
所以别只读高分的那几条就收工。

## 6. 聚类：先聚，别先筛

按「用户在说同一件事」归簇，不是按词形。
`"I want my money back"` 和 `"complete flop"` 是同一簇（买了智商税），
虽然一个字都不重合。

**簇控制在 4-8 个。** 太碎说明你在按词形分，把语义相同的合掉。

常见簇型（不是清单，实际有什么聚什么）：

| 簇型 | 长什么样 | 卖家拿来干嘛 |
|---|---|---|
| **不适合我的肤质/场景** | "didn't work out for me"、"my skin is dry and sensitive" | 详情页要写清适用人群，最高频的一类 |
| **智商税/想退货** | "I want my money back"、"complete flop" | 这个细分品类信任已崩，慎入 |
| **具体使用体验缺陷** | 搓泥、辣眼睛、假白、闷痘 | 详情页从不提但决定复购，逐条抄成 FAQ |
| **诚实测评稀缺** | 评论区在谢博主说实话 | ⚠️ 不是产品痛点，是**内容策略信号** |
| **纯玩梗/互关** | "🙌"、互赞 | **只计数，不成簇** |

⚠️ **转发不算两条独立证据。** 标了 `↻转发自xxx` 的和原帖是同一条内容，
拿它凑数会高估这个痛点的普遍性。

## 7. 落盘

```
cl_save {
  kind: "cl-ig-pain",
  slug: "<产品 slug>",
  data: { ... }
}
```

**slug 由你生成** —— 小写英文 + 短横线：`press-on-nails`、`skincare`。
**不是文件名**，重跑不会覆盖，同一个 slug 的多次运行面板会聚在一起看变化。

### data 的形状

```json
{
  "product": "press-on nails（免胶指甲片）",
  "summary": "一句话：这个品类在 IG 上最核心的信任障碍是什么",
  "pains": [
    {
      "title": "跟风买的爆款，到自己手上就翻车",
      "description": "最密集的一簇。用户不是说产品差，而是说「对我的指甲不成立」…（2-3 句）",
      "frequency": "high",
      "evidence": [
        {
          "text": "逐字原文，一个字都不能改（保留换行、括号、emoji）",
          "zh": "中文意思（必填，英文也要给）",
          "source_type": "post_caption",
          "code": "CfwRnTrprxx",
          "url": "https://www.instagram.com/p/CfwRnTrprxx/",
          "thumbnail_url": "https://scontent-….jpg",
          "username": "dewydisposition",
          "like_count": 600,
          "media_name": "reel",
          "is_paid_partnership": false
        }
      ]
    }
  ],
  "content_signals": ["可选：诚实测评稀缺这类内容侧信号，不是选品结论"],
  "stats": {
    "tags_tried": ["pressonnailreview", "dupealert"],
    "tags_dropped": ["pressonnailsfail"],
    "fetched": 96,
    "signal": 27,
    "search_calls": 12,
    "comment_calls": 6
  },
  "caveats": ["样本来自标签池 + 平台热度排序，不是随机样本…"]
}
```

**必填**：`product`、`pains[]`（每簇要有 `title` 和非空 `evidence[]`，
每条证据要有 `text` / `zh` / `code`）。其余面板会用但不强制。

- `frequency` 只用 `high` / `medium` / `low`，面板按它上色
- `source_type` 用 `post_caption` 或 `comment`
- ⚠️ **`thumbnail_url` 必须从工具输出里逐条透传**，有就一定要带上。
  这是最容易漏的一个字段 —— 实测跑出来的报告 48 条证据**一条都没带**，
  于是面板上一张图都没有。IG 是图像平台，那张图常常就是痛点本身。
  只有两种情况可以没有：评论类证据、album（轮播，实测 0/9 拿不到）。
  它带签名会过期，过期后面板隐藏空位；但用户可以点「看原帖」内嵌看原图，
  所以**过期不是省略它的理由**
- `stats` 如实填你实际跑过的 —— 用户靠它判断覆盖面，也靠它决定要不要重跑

### 每条原话都要逐字 + 中文

**`text` 必须逐字照抄，这是唯一能验证你没编的东西。**

⚠️ 最容易犯的错：**把 caption 的换行拼成一句、顺手删掉括号里的补充**。
原文 `3 PRODUCTS THAT DID NOT WORK OUT FOR ME. (⚠️skincare is subjective)\n\nI usually...`
写成 `3 PRODUCTS THAT DID NOT WORK OUT FOR ME. I usually...` 就**不算逐字了**。

⚠️ **`code` 必须来自工具输出，不能凭印象写。** 编造的 code 会让面板链接 404。
写完核对一遍：每个 `code` 都能在输出里找到，每条 `text` 都能在对应 caption 里搜到。

## 8. 收尾

写完在对话里说：

- 循环走过哪几个标签、弃了哪些（为什么）、扫了多少帖、多少高信号、花了多少钱
- **最值得看的 2-3 个痛点**，各一句话说明它意味着什么
- 如果冒出「诚实测评稀缺」这类**内容侧**信号，单独点出来 —— 那不是选品结论
- 提示结果已经在面板的「IG 痛点」里

**不要把所有簇和原话列在对话里** —— 面板是给这个用的。
对话里只给面板上没有的东西：判断和下一步。

## 一次完整的跑法

```
① cl_ig_hashtag  3个种子标签，pages=1     → 看命中率，弃掉差的
② cl_ig_hashtag  2-4个共现标签，pages=1   → 继续长
③ cl_ig_hashtag  好标签单独 pages=2~3     → 直到新增高信号变少
④ cl_ig_comments 挑 6-8 帖（评论≥30）     → 交叉验证
⑤ 聚类 + 判断
⑥ cl_save
```

一轮完整流程大约消耗 25~60 积分，评论占大头。

| 来源 | 人群 | 用来做 |

| **IG 帖子/评论**（本 skill） | 潜在买家、刷到的人 | 买前顾虑、内容选题 |

那是「买之前听说的」；去 `/cl-reddit-pain` 验证已购用户是不是真这么说。
