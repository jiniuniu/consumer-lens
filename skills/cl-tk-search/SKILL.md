# TK 视频搜索

输入一个品类或需求，输出**这个品类在 TikTok 上真正在带货的视频**，按互动质量排序。

结果落盘后出现在面板的「TikTok」那一格，点开任意一条可以接着拆它的评论区。

## 1. 把意图拆成搜索词

用户给的往往是中文或一句需求，**不要直接拿去搜** —— TikTok 是英文语境，
且单个词召回面太窄。

拆成 **2-4 个英文搜索词**，覆盖不同角度：

| 角度 | 例子（用户说"露营灯"） |
|---|---|
| 品类通用词 | `camping lantern` |
| 使用场景词 | `tent light` |
| 卖点/形态词 | `solar lantern` / `rechargeable camp light` |
| 人群词（可选） | `van life lighting` |

**避免**：太宽的词（`camping`）、太窄的长尾
（`3-in-1 solar camping lantern with fan`）、中文词。

拆完先告诉用户你要搜哪几个词，然后继续，不用等确认。

## 2. 取数

`cl_tk_search` **一次搜一个词**，读完再搜下一个：

```
cl_tk_search { keyword: "camping lantern", pages: 2 }
cl_tk_search { keyword: "tent light",      pages: 2 }
```

- `pages: 2` = 约 40 条/词。3 个词约 120 条，够了。**别贪多**，后面每条都要你读。
- `sort: 1`（默认）按点赞排，找爆款用这个；`sort: 0` 按相关度排，摸品类全貌用那个。
  两者结果差别很大。
- ⚠️ **第 3 页起结果严重重叠**，翻超过 3 页基本是浪费额度。
- 想看最近的趋势用 `days: 30` 或 `90` —— TikTok 爆款一周换一批。

## 3. 规则先筛一遍（这步不用你判断）

工具输出已经把该砍的标在行尾了，照着执行：

- **播放 < 50,000** —— 声量太小，说明不了问题
- **互动率 < 0.5%** —— 典型的「猎奇流量」：很多人划过但没人在意产品
- **重复 aweme_id** —— 服务端已按 id 去重，跨词的重复自己留意

筛完通常剩 40-70 条。

## 4. 逐条读文案，判断是不是种草 ★

**这一步是核心，不能跳，也不能用规则代替。**

看 `desc`（文案）+ 标签 + 作者，把每条归到一类：

| 类型 | 特征 | 留不留 |
|---|---|---|
| **种草** | 展示产品、说卖点、有购买引导（`#tiktokshop`、`link in bio`、@品牌号） | ✅ 留 |
| **评测** | 两个产品对比、说优缺点 | ✅ 留，标注出来 |
| **DIY** | 教怎么用、自己动手做 | ✅ **留**，见下面 |
| **氛围内容** | vlog 顺带出现产品，产品不是主角 | ❌ 砍 |
| **蹭标签** | 打了品类标签但内容无关 | ❌ 砍 |
| **纯搬运** | 明显是转发的素材，无原创 | ❌ 砍 |

⚠️ **DIY 视频是金矿，不是噪声。** 有人自己动手做一个，说明市面上买不到合适的。
遇到 DIY 类的一定留下，并在 `note` 里写清楚**它在解决什么问题**。

⚠️ **注意语种。** 搜英文词会带出葡语、西语的视频（巴西和墨西哥的 TikTok 电商
很活跃）。这些**不要直接砍** —— 如果目标市场是北美，它们说明这个品在拉美
也有需求，值得单独标注。

给每条写一句 `note`：**这条视频对选品说明了什么**。不要复述文案，要说判断。

好的 note：
- 「DIY 自制，说明现成产品的亮度/续航不够」
- 「挂了小黄车，是这个品类的标准带货形式」
- 「葡语，巴西市场，同款在拉美也在推」

差的 note：
- 「一个露营灯的视频」（复述，没判断）
- 「互动率高」（数据里有，不用你说）

## 5. 落盘

用 `cl_save`：

```
cl_save {
  kind: "cl-tk-search",
  slug: "camping-lantern",        // 品类的英文短横线形式
  data: { query, terms, stats, videos }
}
```

结构：

```json
{
  "query": "露营灯",
  "terms": ["camping lantern", "tent light", "solar lantern"],
  "stats": { "fetched": 120, "after_rules": 58, "kept": 23 },
  "videos": [
    {
      "aweme_id": "7392631845109763333",
      "desc": "原文案",
      "url": "https://www.tiktok.com/@xxx/video/xxx",
      "author_name": "xxx",
      "follower_count": 583708,
      "play_count": 12392013,
      "digg_count": 210700,
      "comment_count": 1109,
      "engage_rate": 1.71,
      "create_time": "2026-08-14",
      "hashtags": ["camping", "lantern"],
      "lang": "en",
      "type": "种草",
      "note": "挂了小黄车，这个品类的标准带货形式"
    }
  ]
}
```

- `type` 只能填 `种草` / `评测` / `DIY` / `其他`。面板按它上色和筛选。
- `aweme_id` 必须逐条透传 —— 面板靠它把评论分析挂回这条视频。
- ⚠️ **不要存 `cover` 和 `play_addr`** —— 那是 CDN 签名链接，几小时就失效，
  存了就是一屏破图。面板的封面走实时代理。工具会打回带这两个字段的数据。

**重跑同一个品类就用同一个 slug**，面板会把多次运行聚在一起看变化，
不会覆盖上一次。

## 6. 收尾

写完后告诉用户：

- 搜了哪几个词、原始多少条、筛剩多少条
- **最值得看的 3 条**，各一句话说明为什么
- 提示：结果已经在面板的 TikTok 那一格，点开任意一条可以接着拆评论区

不用把所有视频列在对话里 —— 面板是给这个用的。

## 坑

- **播放量高不等于带货好。** 互动率才是。1200 万播放但互动 0.5% 的，
  多半是被推荐算法带飞的猎奇内容。
- **粉丝数少但互动率高的账号值得注意** —— 那是内容本身有效，不是账号有效。
- **老视频照样有效。** 2023 年的视频现在还在涨评论很正常，别按日期砍。
